📦 Sistema de Vendas com Tkinter e SQLAlchemy
📌 Descrição
Este é um sistema de vendas desenvolvido em Python, utilizando Tkinter para a interface gráfica e SQLAlchemy para a manipulação do banco de dados SQLite. O sistema permite o cadastro de clientes e produtos, armazenando as informações de forma segura e eficiente.

🚀 Funcionalidades
✅ Cadastro de clientes (Nome, Telefone, E-mail)
✅ Cadastro de produtos (Nome, Preço, Estoque)
✅ Armazenamento dos dados em um banco de dados SQLite
✅ Interface gráfica simples e intuitiva
✅ Feedback visual para operações bem-sucedidas ou erros

🛠️ Tecnologias Utilizadas
Python 🐍
Tkinter (Interface Gráfica) 🎨
SQLAlchemy (ORM para Banco de Dados) 🗄️
SQLite (Banco de Dados Relacional)
